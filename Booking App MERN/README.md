# 🏨 Booking App (MERN Stack)

A full-stack **Booking Platform** built with the **MERN stack (MongoDB, Express, React, Node.js)** — inspired by Airbnb.  
Users can register, log in, create and manage their own places, upload images, and make bookings.

---

## 🚀 Features

- 🔐 **User Authentication**
  - Register, log in, and stay authenticated using JWT cookies.
- 🏠 **Property Management**
  - Add, edit, and delete your listings (title, address, photos, description, price, etc.).
- 🖼️ **Photo Upload**
  - Upload from device or by image link, stored securely on **AWS S3**.
- 📅 **Booking System**
  - Users can book available places, view booking details, and see total prices.
- 👤 **User Dashboard**
  - Manage your profile, your listings, and your bookings.
- 💅 **Modern UI**
  - Responsive design with **Tailwind CSS**.

---

## 🧱 Tech Stack

**Frontend:**
- React 18 + Vite
- React Router DOM
- Axios
- Tailwind CSS
- Date-fns

**Backend:**
- Node.js + Express
- MongoDB + Mongoose
- JWT (Authentication)
- Bcrypt (Password Hashing)
- AWS S3 (Image Storage)
- Multer (File Upload)
- Cookie-Parser
- CORS
