# 🌮 The Little Taco Shop

A responsive and accessible static website for **The Little Taco Shop**, built using **HTML**, **CSS**, and a touch of **JavaScript**.  
This project showcases a simple restaurant homepage with a menu, navigation, and supporting pages such as Hours, Contact, and About.

---

## ✨ Features

- 🍴 **Menu Section** – Displays tacos, prices, and add-ons in a clean and accessible table.  
- 📸 **Hero Banner** – Welcomes visitors with an appetizing taco image.  
- 🧭 **Navigation Bar** – Links to Menu, Hours, Contact, and About pages.  
- 📅 **Dynamic Footer** – Automatically updates the current year via JavaScript.  
- ♿ **Accessibility Focus** – Semantic HTML, descriptive alt text, ARIA-friendly structure.  
- 📱 **Responsive Design** – Works seamlessly on desktop and mobile devices.  

---

## 🧱 Tech Stack

- **HTML5** – Semantic, SEO-friendly structure.  
- **CSS3** – Custom styling for layout and design.  
- **JavaScript (Vanilla)** – Handles simple dynamic functionality (e.g., current year).
