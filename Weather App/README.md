# 🌦️ Weather App

A responsive and accessible weather application built with **HTML**, **CSS**, and **JavaScript**, powered by the **OpenWeather API**.  
Users can search for weather conditions anywhere in the world, get forecasts for multiple days, and manage saved locations with ease.

---

## 🧩 Features

- 🔍 **Search by location** – Get real-time weather data for any city, state, or country.  
- 📍 **Get current location** – Fetch weather information using your device’s geolocation.  
- 🏠 **Save home location** – Store your preferred city for quick access.  
- 🌡️ **Toggle units** – Switch between **metric** and **imperial** measurement systems.  
- 🔄 **Refresh data** – Instantly update current weather and forecast information.  
- 📅 **6-day forecast** – View upcoming weather trends for the next several days.  
- ♿ **Accessible design** – ARIA roles, skip links, and offscreen labels improve usability for all users.  

---

## 🛠️ Tech Stack

- **HTML5** – Semantic markup and accessible structure.  
- **CSS3** – Custom styling and responsive design.  
- **JavaScript (ES6+)** – Fetch API, DOM manipulation, and module-based architecture.  
- **Font Awesome** – Icons for UI controls.  
- **Google Fonts (Montserrat)** – Modern typography.  
- **OpenWeather API** – Provides real-time and forecast weather data.
